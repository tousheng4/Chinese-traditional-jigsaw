# 拼筑华夏

> 修复残卷中的屋舍、桥梁、衙署与宫阙，让华夏建筑的记忆重新归册。

一款以中国传统建筑为主题的叙事拼图 iOS App。玩家扮演"修卷者"，在古卷引路人的带领下，通过拼图修复散佚的建筑图卷，逐卷解锁华夏营造的历史记忆。

## 功能概览

### 叙事系统
- 四卷章节剧情，每卷开场由专属引路人与师父展开对话
- 角色对话页（`DialogueSceneView`）：半身人物立绘 + 全屏场景背景，视觉小说风格
- 每关卡配有委托背景、损毁描述、修复目标、师父点评，关卡完成后显示修复报告与封印文字
- 全卷通关后触发终章归册

### 拼图玩法
**网格模式（Grid）**
- 3×3（简单）/ 4×4（标准）/ 6×6（困难）三档难度
- 拼块随机散布或堆叠，拖拽吸附归位
- 计步、计时，记录最佳成绩

**构件模式（Component）**
- 拼放建筑构件（如赵州桥桥台、故宫脊兽等）到画布指定位置
- 每个构件有名称、说明与层级渲染顺序，还原建筑结构逻辑
- 目前收录：赵州桥结构分图、故宫大殿结构分图

### 章节与关卡
| 卷 | 主题 | 收录建筑 |
|----|------|---------|
| 第一卷·人间有屋 | 民居 | 北京四合院、安徽宏村、福建土楼 |
| 第二卷·江河有桥 | 桥梁 | 洛阳桥、赵州桥、卢沟桥 + 赵州桥构件图 |
| 第三卷·一城有序 | 官府 | 淮安府署、阆中贡院、南阳府衙 |
| 第四卷·天下有极 | 皇宫 | 故宫角楼、故宫午门、沈阳故宫 + 故宫构件图 |

关卡按顺序解锁：完成上一卷全部关卡后开启下一卷；同卷内逐页解锁。

### 微注释系统
- 每个拼图关卡配有 `MicroAnnotationPack`，含主注释、次级注释与详情段落
- 完成拼图后在结算页展示建筑知识点（18–34字精短注释 + 进阶详情）

### 成就系统
- **模块成就**：完成各分类全部关卡（民居匠人 / 桥梁鉴赏家 / 衙门达人 / 皇宫探秘者）
- **全局成就**：速度（2分钟内/1分钟内完成）、步数（50步以内/30步以内）、连续通关（3连/5连）、传统文化大师（全通关）、初学者、速通大师
- 成就解锁时显示悬浮 Toast 动画

### 自制拼图（UGC）
- 用户可从相册选取图片，裁剪后生成自定义拼图
- 支持配置网格大小、拼块散布方式、吸附强度
- 可选宣纸 / 素纸 / 绢本纹理，卷轴 / 画框 / 册页边框，自定义封印文字
- 自制关卡不计入成就进度

### 其他
- 音效与触觉反馈（可在设置中关闭）
- 计时器开关（默认关闭）
- 引导遮罩开关
- 降低动画选项（适配无障碍）

**关键设计决策**
- 关卡用 `stableId`（字符串）而非 UUID 做持久化键，保证内容更新后存档不丢失
- `StoryManager` 集中管理章节顺序与解锁逻辑，`ContentManager` 负责关卡注册，两者解耦
- `PuzzleEngine` 吸附阈值基于"单块边长比例"而非绝对像素，适配所有屏幕尺寸
- UGC 图片保存在 App 沙盒 Documents 目录，主图与缩略图分别存储

## 世界观与背景剧情

《华夏营造志》是一部记录中国传统建筑的古卷典籍。不知何故，这部卷册散佚残损，各页图卷碎裂错位，建筑的样貌与记忆正在消散。

玩家扮演"修卷者"，在各卷引路人与师父的指引下，逐页修复这部典籍。

### 四卷引路人

| 引路人 | 所属卷 | 身份 |
|--------|--------|------|
| **院灵·槐安** | 第一卷·人间有屋 | 守着人间烟火的旧院引路人 |
| **桥灵·石衡** | 第二卷·江河有桥 | 记得水势与桥影的渡口引路人 |
| **案吏·闻简** | 第三卷·一城有序 | 替旧档案守着规制的卷中书吏 |
| **宫匠影·玄梁** | 第四卷·天下有极 | 宫阙旧制仍未散去的工匠之影 |

师父作为修复技艺的传授者，在每一关卡开场给出点评与指引。

### 各卷核心立意

- **第一卷**：建筑最早安顿的，是人心。从民居出发，理解人如何在建筑中安身立命。
- **第二卷**：真正高明的桥，不与江河争胜。桥梁修的不是石木，而是相逢。
- **第三卷**：门楼与廊庑，会替时代说出它的规矩。衙署写下秩序、公道与责任。
- **第四卷**：修复宫阙，不是把辉煌擦亮，而是把秩序看清。

### 终章

集齐四卷、修复全部关卡后，触发《终章归册》：

> 《华夏营造志》已修复完成。你修回的不只是孤立的屋宇，而是一部关于家园、道路、秩序与中心的文明卷册。建筑被修复的，从来不只是外表，而是后来者重新理解来处的能力。
